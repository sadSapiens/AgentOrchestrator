# 📋 Краткая сводка проекта

## Что создано

Полнофункциональный **оркестратор AI-агентов** с использованием Google Gemini API и современным веб-интерфейсом.

## 🔥 Новое в версии 1.2 (22 Января 2026)

- � **New Style UI**: Полный редизайн веб-интерфейса в стиле Google Gemini — глубокая темная тема, плавные анимации и "парящее" поле ввода.
- 🌐 **Streamlit Web App**: Полноценное веб-приложение (`app.py`) для удобного управления командой агентов.
- ⚡ **Auto & Direct Modes**: Возможность выбора между автоматическим планированием (Coordinator) и прямым общением с конкретным агентом.
- 📂 **File Context**: Поддержка загрузки файлов и использования их содержимого в качестве контекста для задач.
- 💾 **Session Manager**: Веб-интерфейс для сохранения/загрузки сессий и доступа к истории результатов.

## 📦 Основные компоненты

- ✅ `app.py` - Веб-интерфейс на Streamlit
- ✅ `orchestrator.py` - Ядро управления агентами
- ✅ `agents/` - Команда специализированных агентов (Researcher, Analyzer, Writer, Coordinator)
- ✅ `assets/style.css` - Дизайн-система Gemini Style
- ✅ `utils/web_search.py` - Интеграция с DuckDuckGo для поиска в реальном времени

## 🤖 Команда агентов

| Агент | Функция | Особенности |
|-------|---------|-------------|
| **Researcher** | Поиск и сбор | Доступ в интернет, чтение PDF/TXT |
| **Analyzer** | Аналитика | Структурирование данных, выводы |
| **Writer** | Создание контента | Написание статей, кода, отчетов |
| **Coordinator** | Планирование | Построение графа выполнения |

## 🚀 Быстрый старт

1. Добавьте `GEMINI_API_KEY` в `.env`
2. Запустите веб-интерфейс:
```bash
./venv/bin/streamlit run app.py
```
3. Выберите режим и задайте задачу своей команде AI-агентов.
