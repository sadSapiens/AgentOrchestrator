
### 2. Командная строка
```bash

```

```python

```

## 🤖 Агенты

| Агент | Функция | Формат вывода |
|-------|---------|---------------|
| **Researcher** | Сбор информации | Резюме + Факты + Детали + Выводы |
| **Analyzer** | Анализ данных | Summary + Находки + Тренды + Рекомендации |
| **Writer** | Создание контента | Заголовок + Введение + Основа + Заключение |
| **Coordinator** | Планирование | JSON план с шагами и зависимостями |

## 🔄 Процесс оркестрации

1. **Coordinator** создает план выполнения
2. **Researcher** собирает информацию
3. **Analyzer** анализирует данные (с контекстом от Researcher)
4. **Writer** создает финальный контент (с контекстом от обоих)
5. Возврат структурированного результата

## 🎨 Особенности реализации

### Технологии
- **Google Gemini API** - LLM провайдер
- **Rich** - красивый CLI вывод
- **asyncio** - асинхронное выполнение
- **python-dotenv** - управление конфигурацией

### Архитектурные решения
- **Базовый класс агента** - единый интерфейс
- **Контекстная передача** - агенты обмениваются данными
- **История выполнения** - отслеживание всех задач
- **Гибкая конфигурация** - через .env файл
- **Двухуровневое логирование** - консоль + файл

### Паттерны проектирования
- **Template Method** - BaseAgent с переопределяемыми методами
- **Strategy** - разные агенты для разных задач
- **Singleton** - Logger
- **Factory** - создание агентов в Orchestrator
