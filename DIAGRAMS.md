# 🎨 Визуальные диаграммы

## Архитектура системы

![Architecture](/.gemini/antigravity/brain/4d3a354d-6eff-4a0b-b07d-dafecd07fdfa/orchestrator_architecture_1768963988086.png)

### Описание компонентов

**User / CLI Interface** 💻
- Точка входа для пользователя
- Интерактивный режим и командная строка
- Отправка команд и получение результатов

**Agent Orchestrator** 🤖
- Центральный компонент системы
- Управление всеми агентами
- Координация выполнения задач
- Передача контекста между агентами

**Агенты** 🎭
- **Researcher** 🔍 - Исследование и сбор информации
- **Analyzer** 📊 - Анализ данных и инсайты
- **Writer** ✍️ - Создание контента
- **Coordinator** 🎯 - Планирование задач

**Gemini API** 🔌
- LLM провайдер от Google
- Обработка запросов от агентов
- Генерация ответов

**Утилиты** 🔧
- **Config** ⚙️ - Управление конфигурацией
- **Logger** 📝 - Логирование событий

## Процесс оркестрации

![Workflow](/.gemini/antigravity/brain/4d3a354d-6eff-4a0b-b07d-dafecd07fdfa/workflow_diagram_1768964258118.png)

### Пошаговый процесс

#### 1️⃣ Пользовательский ввод
```
Пример: "Создать отчет о блокчейне"
```

#### 2️⃣ Coordinator создает план
- Анализирует задачу
- Определяет необходимых агентов
- Создает последовательность шагов
- Определяет зависимости

#### 3️⃣ Выполнение шагов

**Шаг 1: Researcher** 🔍
- Собирает информацию о блокчейне
- Структурирует данные
- Выделяет ключевые факты
- **Результат** → передается в контекст

**Шаг 2: Analyzer** 📊
- Получает контекст от Researcher
- Анализирует собранные данные
- Выявляет тренды и паттерны
- Делает выводы
- **Результат** → передается в контекст

**Шаг 3: Writer** ✍️
- Получает контекст от Researcher и Analyzer
- Создает структурированный отчет
- Форматирует контент
- Добавляет заключение
- **Результат** → финальный отчет

#### 4️⃣ Финальный результат ✅
```
Полный отчет о блокчейн технологиях
```

```
└────┬────┘
     │ task
     ▼

     ▼

│  Result         │
```

```
┌─────────┐
│  User   │
└────┬────┘
     │ complex task
     ▼
┌─────────────────┐
│  Orchestrator   │
└────┬────────────┘
     │
     ├─→ Coordinator ──→ Plan
     │
     ├─→ Researcher ──→ Data ──┐

     ├─→ Analyzer ────────────┼──→ Insights ──┐
     │                         │               │ context
```
