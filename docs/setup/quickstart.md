# Быстрый старт

## 1. Получение API ключа Gemini

1. Перейдите на https://makersuite.google.com/app/apikey
2. Войдите с помощью Google аккаунта
3. Создайте новый API ключ
4. Скопируйте ключ

## 2. Настройка проекта

```bash
# Создать .env файл
cp .env.example .env

# Отредактировать .env и добавить ваш API ключ
# GEMINI_API_KEY=ваш-ключ-здесь
```

## 3. Активация виртуального окружения

```bash
# Активировать виртуальное окружение
source venv/bin/activate
```

## 4. Запуск примеров

### Интерактивный режим (рекомендуется для начала)

```bash
python main.py --interactive
```

Доступные команды в интерактивном режиме:
- `list` - показать список агентов
- `task researcher Исследовать тему AI` - выполнить задачу одним агентом
- `orchestrate Создать отчет о блокчейне` - оркестрация нескольких агентов
- `history researcher` - показать историю агента
- `help` - показать справку
- `quit` - выйти

### Командная строка

```bash
# Показать список агентов
python main.py --list

# Выполнить задачу одним агентом
python main.py --agent researcher --task "Исследовать квантовые компьютеры"

# Оркестрация (использует несколько агентов)
python main.py --orchestrate --task "Создать отчет о влиянии AI на образование"
```

### Запуск примеров

```bash
# Запустить файл с примерами
python examples.py
```

## 5. Структура команд

### Одиночный агент

```bash
python main.py --agent <имя_агента> --task "<ваша_задача>"
```

Доступные агенты:
- `researcher` - исследование и сбор информации
- `analyzer` - анализ данных и выявление инсайтов
- `writer` - создание контента
- `coordinator` - планирование и координация

### Оркестрация

```bash
python main.py --orchestrate --task "<сложная_задача>"
```

Оркестратор автоматически:
1. Создаст план выполнения
2. Распределит задачи между агентами
3. Соберет результаты
4. Создаст финальный отчет

## 6. Примеры задач

### Для Researcher
```bash
python main.py --agent researcher --task "Найти информацию о последних достижениях в области квантовых вычислений"
```

### Для Analyzer
```bash
python main.py --agent analyzer --task "Проанализировать тренды развития искусственного интеллекта в 2026 году"
```

### Для Writer
```bash
python main.py --agent writer --task "Написать статью о преимуществах использования AI агентов в бизнесе"
```

### Для оркестрации
```bash
python main.py --orchestrate --task "Создать полный отчет о влиянии блокчейн технологий на финансовую индустрию"
```

## 7. Логи

Все действия логируются в файл `orchestrator.log`. Вы можете просмотреть его:

```bash
tail -f orchestrator.log
```

## 8. Решение проблем

### Ошибка: "GEMINI_API_KEY не установлен"
- Проверьте, что файл `.env` существует
- Убедитесь, что в нем указан `GEMINI_API_KEY=ваш-ключ`

### Ошибка: "ModuleNotFoundError"
- Убедитесь, что виртуальное окружение активировано
- Переустановите зависимости: `pip install -r requirements.txt`

### Медленная работа
- Gemini API может иметь ограничения по скорости
- Попробуйте уменьшить `MAX_TOKENS` в `.env`

## 9. Дополнительная настройка

Отредактируйте `.env` для настройки параметров:

```env
GEMINI_API_KEY=ваш-ключ
MODEL_NAME=gemini-2.0-flash-exp  # или другая модель
TEMPERATURE=0.7                   # креативность (0.0-1.0)
MAX_TOKENS=2048                   # максимум токенов в ответе
LOG_LEVEL=INFO                    # уровень логирования
```
