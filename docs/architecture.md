# Архитектура оркестратора агентов

## Обзор

Оркестратор агентов - это система для управления несколькими специализированными AI-агентами, которые работают вместе для выполнения сложных задач.

## Компоненты системы

### 1. Базовый агент (`BaseAgent`)

Абстрактный базовый класс для всех агентов.

**Основные возможности:**
- Интеграция с Gemini API
- Асинхронное выполнение задач
- История выполнения
- Контекстная передача данных

**Методы:**
- `execute(task, context)` - выполнить задачу
- `get_history()` - получить историю выполнения
- `get_capabilities()` - получить описание возможностей

### 2. Специализированные агенты

#### ResearcherAgent (Исследователь)
**Роль:** Сбор и структурирование информации

**Возможности:**
- Исследование тем
- Поиск фактов
- Сбор данных
- Структурирование информации

**Формат вывода:**
- Краткое резюме
- Ключевые факты
- Детальная информация
- Выводы и рекомендации

#### AnalyzerAgent (Аналитик)
**Роль:** Анализ данных и выявление инсайтов

**Возможности:**
- Анализ данных
- Выявление паттернов
- Генерация инсайтов
- Оценка рисков

**Формат вывода:**
- Executive summary
- Ключевые находки
- Детальный анализ
- Тренды и паттерны
- Рекомендации

#### WriterAgent (Писатель)
**Роль:** Создание структурированного контента

**Возможности:**
- Создание контента
- Редактирование текстов
- Форматирование
- Адаптация стиля

**Формат вывода:**
- Заголовок
- Введение
- Основная часть
- Заключение

#### CoordinatorAgent (Координатор)
**Роль:** Планирование и координация работы агентов

**Возможности:**
- Разбиение задач
- Планирование последовательности
- Координация агентов
- Синтез результатов

**Формат вывода (JSON):**
```json
{
  "plan": [
    {
      "step": 1,
      "agent": "researcher",
      "task": "описание",
      "depends_on": []
    }
  ],
  "expected_outcome": "описание"
}
```

### 3. Оркестратор (`AgentOrchestrator`)

Главный компонент для управления агентами.

**Основные методы:**

#### `execute_single_task(agent_name, task, context)`
Выполнить задачу одним агентом.

**Параметры:**
- `agent_name` - имя агента
- `task` - задача для выполнения
- `context` - дополнительный контекст (опционально)

**Возвращает:** результат выполнения (строка)

#### `orchestrate_task(task)`
Оркестрировать выполнение сложной задачи.

**Процесс:**
1. Координатор создает план
2. Выполнение плана по шагам
3. Передача контекста между агентами
4. Синтез финального результата

**Возвращает:** словарь с результатами всех шагов

#### `list_agents()`
Получить список всех агентов и их возможностей.

#### `get_agent_history(agent_name)`
Получить историю выполнения задач агента.

## Поток данных

### Одиночная задача
```
Пользователь → Оркестратор → Агент → Gemini API → Результат
```

### Оркестрация
```
Пользователь → Оркестратор
                    ↓
              Coordinator (создание плана)
                    ↓
              Researcher (сбор информации)
                    ↓ (контекст)
              Analyzer (анализ)
                    ↓ (контекст)
              Writer (создание контента)
                    ↓
              Финальный результат
```

## Контекст и передача данных

Каждый агент может получать контекст от предыдущих агентов:

```python
context = {
    "researcher_result": "...",
    "analyzer_result": "...",
    "custom_param": "..."
}
```

Контекст автоматически передается в промпт агента.

## Логирование

Система использует Rich для красивого вывода и стандартное логирование для файлов.

**Уровни логирования:**
- INFO - общая информация
- WARNING - предупреждения
- ERROR - ошибки
- DEBUG - отладочная информация

**Специальные методы логирования:**
- `logger.agent_action(agent, action, details)` - действия агента
- `logger.task_start(task)` - начало задачи
- `logger.task_end(task, success)` - завершение задачи

## Конфигурация

Все настройки хранятся в `.env` файле:

```env
# API настройки
GEMINI_API_KEY=your-key
MODEL_NAME=gemini-2.0-flash-exp
TEMPERATURE=0.7
MAX_TOKENS=2048

# Логирование
LOG_LEVEL=INFO
LOG_FILE=orchestrator.log
```

## Расширение системы

### Добавление нового агента

1. Создайте класс, наследующий `BaseAgent`:

```python
from agents.base_agent import BaseAgent

class MyAgent(BaseAgent):
    def __init__(self):
        super().__init__(
            name="MyAgent",
            role="Моя роль",
            system_prompt="Инструкции для агента"
        )

    def get_capabilities(self):
        return {
            "capability1": "Описание возможности 1",
            "capability2": "Описание возможности 2"
        }
```

2. Добавьте агента в оркестратор:

```python
# В orchestrator.py
from agents.my_agent import MyAgent

class AgentOrchestrator:
    def __init__(self):
        self.agents = {
            # ... существующие агенты
            "myagent": MyAgent()
        }
```

3. Обновите координатора для использования нового агента.

## Обработка ошибок

Система включает обработку ошибок на нескольких уровнях:

1. **Валидация конфигурации** - проверка API ключа
2. **Обработка ошибок API** - повторные попытки и логирование
3. **Обработка ошибок агентов** - продолжение работы при ошибке одного агента
4. **Логирование всех ошибок** - для отладки

## Производительность

**Оптимизации:**
- Асинхронное выполнение задач
- Кэширование результатов в истории
- Ограничение размера контекста

**Рекомендации:**
- Используйте `MAX_TOKENS` для контроля размера ответов
- Настройте `TEMPERATURE` для баланса креативности/точности
- Мониторьте использование API через логи

## Безопасность

**Рекомендации:**
- Храните API ключ в `.env` (не коммитьте в git)
- Используйте переменные окружения в продакшене
- Ограничьте доступ к логам (могут содержать чувствительные данные)
- Валидируйте пользовательский ввод

## Тестирование

Для тестирования системы:

```bash
# Запустить примеры
python examples.py

# Интерактивный режим
python main.py --interactive

# Список агентов
python main.py --list
```

## Ограничения

1. **API лимиты** - Gemini API имеет ограничения по количеству запросов
2. **Размер контекста** - ограничен MAX_TOKENS
3. **Последовательное выполнение** - агенты выполняются последовательно
4. **Зависимость от API** - требуется подключение к интернету
