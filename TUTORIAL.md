## Урок 2: Работа с одиночными агентами

### Researcher (Исследователь)

**Задача:** Собрать информацию о квантовых компьютерах

```
> task researcher Исследовать основные принципы работы квантовых компьютеров
```

**Что происходит:**
1. Агент получает задачу
2. Формирует промпт для Gemini API
3. Получает ответ
4. Структурирует информацию
5. Возвращает результат

**Ожидаемый результат:**
- Краткое резюме
- Ключевые факты о кубитах, суперпозиции, запутанности
- Детальная информация
- Выводы

### Analyzer (Аналитик)

**Задача:** Проанализировать тренды в AI

```
> task analyzer Проанализировать основные тренды развития искусственного интеллекта в 2026 году
```

**Ожидаемый результат:**
- Executive summary
- Ключевые тренды (LLM, multimodal AI, etc.)
- Детальный анализ каждого тренда
- Прогнозы и рекомендации

### Writer (Писатель)

**Задача:** Создать статью

```
> task writer Написать статью на 500 слов о преимуществах использования AI агентов в бизнесе для бизнес-журнала
```

**Ожидаемый результат:**
- Привлекательный заголовок
- Захватывающее введение
- Структурированная основная часть
- Убедительное заключение

### Coordinator (Координатор)

**Задача:** Создать план проекта

```
> task coordinator Создать детальный план разработки мобильного приложения для онлайн-обучения
```

**Ожидаемый результат:**
- JSON с планом выполнения
- Разбиение на шаги
- Распределение задач
- Зависимости между задачами

## Урок 3: Оркестрация задач

### Простая оркестрация

**Задача:** Создать отчет о блокчейне

```
> orchestrate Создать краткий отчет о применении блокчейн технологий в финансовой индустрии
```

**Что происходит:**
1. **Coordinator** создает план:
   - Шаг 1: Researcher соберет информацию
   - Шаг 2: Analyzer проанализирует данные
   - Шаг 3: Writer создаст отчет

2. **Researcher** исследует тему:
   - Собирает факты о блокчейне
   - Находит примеры использования
   - Структурирует информацию

3. **Analyzer** анализирует (получает контекст от Researcher):
   - Выявляет ключевые тренды
   - Оценивает влияние на финансы
   - Делает выводы

4. **Writer** создает отчет (получает контекст от обоих):
   - Формирует структуру
   - Пишет текст
   - Форматирует результат

### Сложная оркестрация

**Задача:** Комплексное исследование

```
> orchestrate Провести полное исследование рынка электромобилей, включая анализ конкурентов, трендов, технологий и прогнозов на 5 лет
```

**Процесс:**
1. Coordinator разбивает на подзадачи
2. Researcher собирает данные о рынке
3. Analyzer анализирует конкурентов
4. Researcher исследует технологии
5. Analyzer делает прогнозы
6. Writer создает финальный отчет

## Урок 5: Работа с контекстом

### Программное использование

Создайте файл `my_task.py`:

```python
import asyncio
from orchestrator import AgentOrchestrator

async def main():
    orchestrator = AgentOrchestrator()
    
    # Шаг 1: Исследование
    research = await orchestrator.execute_single_task(
        "researcher",
        "Исследовать последние достижения в области квантовых вычислений"
    )
    
    # Шаг 2: Анализ с контекстом
    analysis = await orchestrator.execute_single_task(
        "analyzer",
        "Проанализировать перспективы коммерциализации",
        context={"research_data": research}
    )
    
    # Шаг 3: Создание контента
    article = await orchestrator.execute_single_task(
        "writer",
        "Написать статью для технического журнала",
        context={
            "research": research,
            "analysis": analysis,
            "target_audience": "технические специалисты",
            "length": "800-1000 слов"
        }
    )
    
    print(article)

if __name__ == "__main__":
    asyncio.run(main())
```

Запуск:
```bash
source venv/bin/activate
python my_task.py
```

## Урок 8: Автоматизация

### Bash скрипт для регулярных задач

Создайте `daily_research.sh`:

```bash
#!/bin/bash

TOPICS=(
    "Квантовые компьютеры"
    "Искусственный интеллект"
    "Блокчейн технологии"
)

for topic in "${TOPICS[@]}"; do
    echo "Исследую: $topic"
    ./run.sh --agent researcher --task "Исследовать последние новости о: $topic" \
        > "reports/$(date +%Y%m%d)_${topic// /_}.txt"
done
```

### Python скрипт для пакетной обработки

Создайте `batch_process.py`:

```python
import asyncio
from orchestrator import AgentOrchestrator

async def process_topics(topics):
    orchestrator = AgentOrchestrator()
    
    for topic in topics:
        print(f"\n{'='*60}")
        print(f"Обработка: {topic}")
        print('='*60)
        
        result = await orchestrator.orchestrate_task(
            f"Создать краткий отчет о: {topic}"
        )
        
        # Сохранить результат
        filename = f"reports/{topic.replace(' ', '_')}.txt"
        with open(filename, 'w', encoding='utf-8') as f:
            f.write(result.get('final_result', ''))
        
        print(f"Сохранено в: {filename}")

topics = [
    "Квантовые вычисления",
    "Блокчейн в финансах",
    "AI в медицине"
]

asyncio.run(process_topics(topics))
```

## Урок 10: Расширение системы

### Создание собственного агента

1. Создайте `agents/translator.py`:

```python
from agents.base_agent import BaseAgent

class TranslatorAgent(BaseAgent):
    def __init__(self):
        super().__init__(
            name="Translator",
            role="Агент-переводчик",
            system_prompt="""
            Ты - профессиональный переводчик.
            Твоя задача - точно переводить тексты,
            сохраняя смысл и стиль оригинала.
            """
        )
    
    def get_capabilities(self):
        return {
            "translation": "Перевод текстов",
            "localization": "Локализация контента"
        }
```

2. Добавьте в `agents/__init__.py`:

```python
from .translator import TranslatorAgent
__all__ = [..., 'TranslatorAgent']
```

3. Зарегистрируйте в `orchestrator.py`:

```python
from agents import TranslatorAgent

class AgentOrchestrator:
    def __init__(self):
        self.agents = {
            ...,
            "translator": TranslatorAgent()
        }
```

4. Используйте:

```
> task translator Перевести на английский: Привет, мир!
```
