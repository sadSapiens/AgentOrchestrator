# Руководство по CLI

## Обзор

CLI оркестратора агентов предоставляет два режима работы:
1. **Интерактивный режим** - для пошаговой работы с агентами
2. **Командная строка** - для автоматизации и скриптов

## Интерактивный режим

### Запуск

```bash
python main.py --interactive
# или просто
python main.py -i
# или без параметров
python main.py
```

### Доступные команды

#### `list`
Показать список всех доступных агентов и их возможностей.

```
> list
```

#### `task <agent> <задача>`
Выполнить задачу одним агентом.

**Примеры:**
```
> task researcher Исследовать квантовые компьютеры
> task analyzer Проанализировать тренды в AI
> task writer Написать статью о блокчейне
```

#### `orchestrate <задача>`
Выполнить сложную задачу с использованием нескольких агентов.

**Примеры:**
```
> orchestrate Создать отчет о влиянии AI на образование
> orchestrate Исследовать и проанализировать рынок криптовалют
```

#### `history <agent>`
Показать историю выполнения задач агента.

**Примеры:**
```
> history researcher
> history analyzer
```

#### `help`
Показать справку по командам.

```
> help
```

#### `quit` / `exit` / `q`
Выйти из интерактивного режима.

```
> quit
```

## Режим командной строки

### Показать список агентов

```bash
python main.py --list
```

### Выполнить задачу одним агентом

```bash
python main.py --agent <имя_агента> --task "<задача>"
```

**Примеры:**

```bash
# Researcher
python main.py --agent researcher --task "Исследовать последние достижения в области квантовых вычислений"

# Analyzer
python main.py --agent analyzer --task "Проанализировать текущие тренды в области искусственного интеллекта"

# Writer
python main.py --agent writer --task "Написать краткую статью о преимуществах использования AI агентов"

# Coordinator
python main.py --agent coordinator --task "Создать план для разработки новой функции"
```

### Оркестрация (несколько агентов)

```bash
python main.py --orchestrate --task "<сложная_задача>"
```

**Примеры:**

```bash
# Полный отчет
python main.py --orchestrate --task "Создать полный отчет о влиянии блокчейн технологий на финансовую индустрию"

# Исследование и анализ
python main.py --orchestrate --task "Исследовать и проанализировать перспективы развития квантовых компьютеров"

# Комплексная задача
python main.py --orchestrate --task "Подготовить презентацию о будущем искусственного интеллекта"
```

### Без флага --orchestrate

Если не указан `--agent`, но указан `--task`, система автоматически использует оркестрацию:

```bash
python main.py --task "Создать отчет о блокчейне"
# Эквивалентно:
python main.py --orchestrate --task "Создать отчет о блокчейне"
```

## Параметры командной строки

### Основные параметры

| Параметр | Короткая форма | Описание |
|----------|----------------|----------|
| `--agent` | - | Имя агента для выполнения задачи |
| `--task` | - | Задача для выполнения |
| `--orchestrate` | - | Использовать оркестрацию |
| `--list` | - | Показать список агентов |
| `--interactive` | `-i` | Интерактивный режим |

### Примеры комбинаций

```bash
# Только список
python main.py --list

# Интерактивный режим
python main.py --interactive
python main.py -i
python main.py  # без параметров

# Одиночный агент
python main.py --agent researcher --task "Задача"

# Оркестрация (явно)
python main.py --orchestrate --task "Задача"

# Оркестрация (неявно)
python main.py --task "Задача"
```

## Форматирование вывода

CLI использует библиотеку Rich для красивого форматирования:

- **Цветной вывод** - разные цвета для разных типов информации
- **Таблицы** - для списка агентов
- **Панели** - для результатов
- **Markdown** - для форматированного текста
- **Прогресс-бары** - для длительных операций

## Логирование

### Консольный вывод

Все действия отображаются в консоли с временными метками и цветовым кодированием:

```
[08:49:41] INFO  ✓ Агент 'Researcher' инициализирован
[08:49:42] INFO  Researcher → Начало выполнения: Исследовать...
[08:49:45] INFO  Researcher → Завершено: Результат: 1234 символов
```

### Файл логов

Все события также записываются в `orchestrator.log`:

```bash
# Просмотр логов в реальном времени
tail -f orchestrator.log

# Последние 50 строк
tail -n 50 orchestrator.log

# Поиск ошибок
grep ERROR orchestrator.log
```

## Переменные окружения

Можно переопределить настройки через переменные окружения:

```bash
# Временно изменить модель
MODEL_NAME=gemini-1.5-pro python main.py --task "Задача"

# Изменить температуру
TEMPERATURE=0.9 python main.py --agent writer --task "Творческая задача"

# Изменить уровень логирования
LOG_LEVEL=DEBUG python main.py --interactive
```

## Скрипты и автоматизация

### Bash скрипт

```bash
#!/bin/bash

# research.sh - Автоматическое исследование темы

TOPIC=$1

if [ -z "$TOPIC" ]; then
    echo "Использование: ./research.sh <тема>"
    exit 1
fi

source venv/bin/activate

python main.py --orchestrate --task "Создать полный отчет о: $TOPIC"
```

Использование:
```bash
chmod +x research.sh
./research.sh "квантовые компьютеры"
```

### Python скрипт

```python
#!/usr/bin/env python3
import asyncio
from orchestrator import AgentOrchestrator

async def main():
    orchestrator = AgentOrchestrator()
    
    topics = [
        "Квантовые компьютеры",
        "Блокчейн технологии",
        "Искусственный интеллект"
    ]
    
    for topic in topics:
        result = await orchestrator.execute_single_task(
            "researcher",
            f"Исследовать: {topic}"
        )
        print(f"\n{'='*60}")
        print(f"Тема: {topic}")
        print(f"{'='*60}")
        print(result[:500])

if __name__ == "__main__":
    asyncio.run(main())
```

## Обработка ошибок

### Отсутствует API ключ

```
Ошибка: GEMINI_API_KEY не установлен
```

**Решение:**
1. Создайте файл `.env`
2. Добавьте `GEMINI_API_KEY=ваш-ключ`

### Неизвестный агент

```
Ошибка: Агент 'unknown' не найден
```

**Решение:**
Используйте `python main.py --list` для просмотра доступных агентов.

### Ошибка API

```
Ошибка при выполнении задачи: API error
```

**Возможные причины:**
- Неверный API ключ
- Превышен лимит запросов
- Проблемы с сетью

## Советы и лучшие практики

### 1. Формулировка задач

**Хорошо:**
```bash
python main.py --agent researcher --task "Исследовать основные принципы квантовых вычислений, включая кубиты, суперпозицию и запутанность"
```

**Плохо:**
```bash
python main.py --agent researcher --task "квантовые компьютеры"
```

### 2. Использование контекста

Для сложных задач используйте оркестрацию - она автоматически передает контекст между агентами.

### 3. Выбор агента

- **Researcher** - для сбора информации
- **Analyzer** - для анализа данных
- **Writer** - для создания контента
- **Coordinator** - для планирования
- **Orchestrate** - для комплексных задач

### 4. Мониторинг

Следите за логами для отладки:
```bash
tail -f orchestrator.log | grep ERROR
```

### 5. Производительность

- Используйте конкретные задачи для одиночных агентов
- Оркестрацию - только для сложных задач
- Настройте `MAX_TOKENS` для контроля размера ответов

```bash

```

```bash

```

